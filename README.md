# Hardware Hub

[![Live Demo](https://img.shields.io/badge/demo-live-blue)](https://hardware-hub-demo.up.railway.app)

Internal application for managing, renting, and tracking company hardware. Built with FastAPI, SQLAlchemy, React, TypeScript, and Vite.

## Features

- Admin and user authentication
- Hardware inventory management
- Rental engine with business-rule guards
- AI-powered semantic search
- Smart Assistant and Inventory Auditor *(planned — see [AI_FEATURES_PLAN.md](AI_FEATURES_PLAN.md))*

## Tech Stack

- **Backend:** FastAPI, SQLAlchemy, Pydantic, Alembic, SQLite
- **Frontend:** React, TypeScript, Vite, Tailwind CSS, React Router
- **AI:** OpenRouter (OpenAI-compatible)
- **Deployment:** Railway (full-stack), Docker

## Local Development

```bash
# Backend
cd backend
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
alembic upgrade head
python -m app.seed
uvicorn app.main:app --reload

# Frontend
cd frontend
npm install
npm run dev
```

The backend runs on `http://localhost:8000` and the frontend on `http://localhost:5173`.

## Deployment

The project is configured for deployment on **Railway**:

1. Push this repository to GitHub.
2. In Railway, create a new project from the GitHub repo.
3. Add **two services**:
   - **Backend service** (root directory: `backend/`)
   - **Frontend service** (root directory: `frontend/`)
4. Add a **Volume** to the backend service and mount it at `/app/data`.
5. Set the environment variables from `.env.example`.
6. Deploy and copy the public frontend URL into this README.

See `.env.example` for the full list of required environment variables.

## Environment Variables

Copy `.env.example` to `.env` and fill in your values:

```bash
# Backend
DATABASE_URL=sqlite:///./data/hardware_hub.db
SECRET_KEY=change-me-in-production
OPENROUTER_API_KEY=
ADMIN_EMAIL=admin@booksy.com
ADMIN_PASSWORD=ChangeMe123!
CORS_ORIGINS=http://localhost:5173

# Frontend
VITE_API_URL=http://localhost:8000
```
